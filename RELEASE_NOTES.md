# Version 1.0.0

Initial pre-launch landing page for Travis Fitness Consulting.

- Responsive charcoal, ivory, and bronze design.
- Dedicated service sections for gyms, hospitality, and private clients.
- Consulting approach and founder story.
- Consultation form preview with service selection and browser validation.
- Self-contained static website with no build dependencies.

The form does not send or store inquiries. Hosting, custom domain, and live inquiry handling are not configured in this release.
